# Drumroll 1.2.0-kb.10

`kb.10` gives returning practice a clear musical arc: choose one short set at
the kit, earn a saved musical receipt, and see how that work moves a favourite
song forward. It integrates P0 in `a6e69ea` and P1 in `455e898`.

## One practice set with a payoff

- Home now composes an evidence-backed Focus → Build → Payoff route. The first
  action remains armed at the kit, with the existing direct physical start and
  manual fallbacks intact.
- A primary goal with a trustworthy path can surface its next safe song section
  and prerequisite. Thin evidence stays an honest “building evidence” state,
  rather than a readiness forecast.
- The session can be short or full without changing the learner's global
  difficulty or blocking free choice.

## Receipts over attendance theatre

- A finished run puts an evidence-backed musical delta, its meaning, and one
  useful next action before XP, daily progress, streak, or an achievement.
- “Practice streak” and “today's set” have separate meanings. A lapse starts a
  new set without deleting mastery, goal evidence, XP, stars, or access to the
  next action.
- Achievements now favour retained skills, comparable timing improvement, clean
  targeted loops, and meaningful song-section proof before volume milestones.

## Evidence routes through the week

- Home can show evidence-backed Review, Build, and Apply cards. A card points
  to saved learner evidence, can be swapped for another valid candidate, and
  remains possible after the calendar changes.
- Profile keeps a weekly rhythm with played days, planned rests, and the next
  available session. Planned rests are visible but unscored.
- A prerequisite or retained-skill milestone can offer a bounded song-section
  audition. Its result returns to a named prerequisite or updates the saved
  goal path; it does not claim full-song readiness.
- The weekly recap reports only local saved evidence: actual sessions, one
  skill signal, one reached section where available, and the next useful work.
- Phrase tiers make the live clean-hit streak peripheral musical feedback. A
  miss clears the moment without punitive loss language; reduced motion keeps
  the count and tier readable.

## Evidence boundary

Physical Yamaha DTX402 cable-cycle behavior and a complete hands-free playing
session still require the connected kit. MIDI cannot establish posture, grip,
rebound, muscular tension, acoustic tone, or injury safety. Retention and
transfer claims need longitudinal learner and teacher evidence. Protected music
is not made available by a metadata row, a same-title match, or a chart alone.
