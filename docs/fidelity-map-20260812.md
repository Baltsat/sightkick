## what this is

This maps the owner’s distinct asks to the behavior-bearing source at `19bbfc6`, the current checkout where the code still exists, and the strongest screen evidence available on 2026-08-12. `9a9fd80` adds the acceptance note; it does not change product behavior. Concurrent uncommitted work is deliberately not treated as shipped evidence.

The evidence classes matter:

- **installed** means the signed `/Applications/Drumroll.app` v1.2.0 build 1.2.12, captured in `docs/design-qa/2026-08-12-installed-verify/`. It predates `19bbfc6`.
- **QA render** means a browser/story/render capture. It proves a surface can render, not that the installed application or a physical kit did it.
- **source only** means code exists but no current installed or physical-kit observation exists. It is not a user-experience claim.

`MATCHES` means the request, implementation, and a shown surface agree. `DIVERGES` means the owner asked for X, code does Y, and he sees Z; code existing is not enough. `ABSENT` means no credible product path currently delivers the ask. A match is not a release claim.
